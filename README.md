# Analisis_Portafolio 

El análisis de un portafolio de inversiones consiste en evaluar un conjunto de activos financieros para optimizar el equilibrio entre el rendimiento esperado y el nivel de riesgo asumido.  

El proyecto pretende aplicar conocimientos sobre análisis financiero destinado a un portafolio con multiples compañias y sectores, analizando aspectos estructurales de un portafolio.  La obtención y preparación de los datos se realizó mediante yfinance para obtener los datos históricos de las empresas en un periodo determinado.  

Las métricas seleccionadas responden a:  
1)**Retorno Esperado Anual**: La rentabilidad promedio esperada en las inversiones de las compañias seleccionadas.   

2)**Volatilidad Anual** Mide la variabilidad y el riesgo presente en el portafolio. Entre mayor volatilidad, mayor incertidumbre. 

3)**Indice de Sharpe:** Indicador para medir el rendimiento ajustado al riesgo.
